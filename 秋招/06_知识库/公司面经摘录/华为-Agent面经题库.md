# 华为-Agent面经题库

只列问题，不写答案。工作区原先没有华为题库，本文件是新建。若 Obsidian 里已有同名题库，请把下面的问句按语义并进原编号，不要整文件覆盖。来源与证据等级见 [[秋招/08_面试准备/华为-AI应用/常见问题与面经汇总|常见问题与面经汇总]]。单帖问法不称高频。

#行为面

1. 请做一个自我介绍。技术面大约两到三分钟，主管面可能要讲到五分钟。
2. 介绍自己的教育背景，以及学过哪些专业课。
3. 学校成绩大概排在什么位置？
4. 老家是哪里？高考多少分？
5. 家在哪，期望的 base 在哪？
6. 你是否了解华为的文化或相关理念？你自己的理解是什么？
7. 请用「遇到什么问题、你怎么想、做了什么、结果是什么、用什么指标评价」讲一段经历。
8. 对方没把问题问清楚时，你怎么确认他真正想要的？
9. 你面试华为的优势和劣势分别是什么？
10. 你怎么学习一块新的知识？
11. 团队里意见冲突时你怎么处理？
12. 最自豪的一件事是什么？最让你愤怒的一件事是什么？
13. 未来三到五年的职业规划是什么？期望薪资大概是多少？
14. 科研或项目里碰到困难，你怎么拆开问题并解决？
15. 团队里你更多是主导还是配合？协作中有什么体会？
16. 怎么看待压力？怎么看 AI 以后会怎样？怎么理解华为的精神文化？[题干待核实：2026-02-10 主管面只点了这几个词，没有展开成完整问句；该场明确没有问职业规划、自评优缺点和薪资]

#项目深挖

1. 实习做了什么业务，你负责哪些模块，产出是什么？
2. 介绍一个项目的整体设计、技术选型和你负责的部分。
3. 项目从开始到完成的时间线是怎样的，每个阶段你做了什么？
4. 你提出的方案能不能复用到别的场景？

#RAG

1. RAG 在 Agent 里起什么作用，检索和生成怎么接？

#Agent

1. 一个基于 ReAct、再加检索的 Agent，哪些模块是你写的，哪些只是熟悉架构？
2. 用来完成重复操作的 Computer Use / GUI Agent，背景和结构怎么划分？
3. Skill 和 MCP 分别解决什么问题？
4. Agent 是什么？宏观架构有哪些部分？
5. 如果从零准备一个 Agent 系统，你会怎么设计？
6. 模型能力评估和 Agent 实现分别看什么？

#模型与训练

3. 大模型训练数据如何清洗，数据集配比怎么定？
4. LoRA 微调时训练出了问题，怎么定位？
5. 常见的聚类算法有哪些，差别是什么？
6. LSTM 和 RNN 的工作机制是什么？
7. 模型效果和预期不符时怎么排查？
8. 有监督和无监督分别指什么？
9. 深度学习和强化学习分别指什么？
