# 华为 AI 应用 / Agent：常见问题与面经汇总

更新于：2026-10-04

岗位锚点是华为校招里和 Agent、AI 技术应用、大模型应用接近的面试，不是某一张岗卡的复述。帖子里实际出现的岗位还有：某 BG 的 Agent 实习、AI 应用工程师、AI 应用工程师-AI 技术应用、车 BU 多模态大模型算法、AI 岗机器学习，以及一篇没写岗位名的 26 届本科校招。

## 核心结论：最重要的考察点

能对上两篇以上独立帖的，只有这几类：自我介绍、把实习或项目讲清楚（业务、模块、你负责的部分）、以及 base / 工作地。除此之外不要说「华为 Agent 岗就考这些」。

单帖里反复出现的形态是：

- 技术面先讲经历，再问和简历相关的基础概念（网络、语言、模型、Agent 架构），然后手撕一道。
- 主管面不一定再手撕。有的场几乎还是技术（Agent 实习主管面），有的场改问文化、城市、冲突、规划和指标（车 BU 三面、2025-10-27 三面）。
- 手撕题面以当场口述为准。有名字的就记名字；原文没给输入输出和样例的，不补。

## 直接面经综合分析

AI 技术应用这场（2026-05-14，杭州研究所，云软件研发）和画像最接近：专业面没有八股清单，要实习、项目架构和一道三数之和；主管面问困难、时间线、协作，以及 Agent 的概念、宏观架构和怎么设计一个 Agent。流程上是双机位。5 月 15 日 HR 打电话沟通 base 杭州，这是流程，不是一道面试题。

Agent 实习这场（页面时间 07-18，按抓取日 2026-10-04 记为 2026 年；作者是大二）更贴 Agent 实现：ReAct、检索、Skill、MCP、Computer Use，外加 TCP、C 语言存储和编译，手撕拓扑排序。主管面仍然偏技术，几乎没有软素质题。

AI 应用工程师一面（2026-01-20）只考了 Transformer、7B BF16 显存，以及「每个数 +K 或 -K 后的最小极差」。作者说后来问 HR，被告知挂了就基本告别这条开发流程。帖里没有 HR 问句。

车 BU 多模态算法是 2026-09-17 的线下二面和主管三面。二面关键词是数据清洗、配比、LoRA、训练问题和 Agent 实现，手撕是单词 Top-K。三面离开技术，改问问题—思考—行动—结果—指标、城市和华为文化。作者更新结果是主管挂。

2025-10-27 的 AI 岗机器学习是三轮线下：聚类、LSTM/RNN、字符串解码变体、最长连续子数组，以及优势劣势、学习、冲突、自豪/愤怒、规划、薪资、base。岗位不是 Agent 应用，题按 B 级收入，不写成 Agent 岗必考。

26 届本科这场（2026-02-10）没写岗位名。专业面问监督/无监督、深度学习/强化学习，并手撕 k 近邻和矩阵最长递增序列。主管面点了团队、压力、AI 未来、精神文化，并写明没有问职业规划、优缺点和薪资。问句没有展开，题库里标了待核实。

- Agent 实习帖的页面只有「07-18 01:12」，没有公元年。面试月份是 4 月投递、6 月技术面、7 月主管面。这里按抓取日把帖子时间记成 2026-07-18。
- 单词 Top-K 的返回值，作者自己前后不一致。
- 「等于目标值的最长连续子数组」没有定义目标值是和还是元素。
- 字符串解码只说是 hot100 变体。
- 26 届本科主管面的「团队、压力、AI 未来、精神文化」不是完整问句。
- 2025-10-27 的「模型微调等」没有单独成题，避免和车 BU 的 LoRA 题叠成两道空题。
