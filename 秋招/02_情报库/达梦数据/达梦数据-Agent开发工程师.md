## 岗位简介
【岗位职责】
1. 协助开发基于大语言模型的 AI Agent，完成任务拆解、工具调用等基础功能开发。
2. 配合完成 Prompt 设计与优化，结合 RAG 技术优化知识库，提升 Agent 响应准确性。
3. 协助进行 Agent 系统的测试、部署与运维，参与 CI/CD 流水线搭建与问题排查。

【任职要求】
1. 本科及以上学历，计算机、人工智能等相关专业。
2. 掌握 Python 编程，熟悉 RESTful API 开发，了解 Docker、Kubernetes 基础概念。
3. 有 OpenCloud Harness 平台使用或适配经验者优先，能快速上手云环境下的 Agent 开发。
4. 了解大模型基本原理及 Prompt Engineering，有 RAG 应用实践经验者加分。
5. 具备学习能力与团队协作意识，能跟进 Agent 及云原生技术动态。

- 匹配理由：全职校招，职责是大模型 Agent 的任务拆解、工具调用、Prompt 与 RAG；本科及以上，硕士可投。
