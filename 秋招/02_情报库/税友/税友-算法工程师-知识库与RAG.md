## 岗位简介
岗位职责】
1. 参与 AI Agent 的设计与开发：和业务、产品一起，把财税场景任务（政策问答、申报辅助、票据处理等）做成能自动跑通的 AI 功能。
2. 建设知识库系统：知识切片、知识图谱、RAG 检索链路的开发与优化，答案可溯源到原文。
3. 做技术调研与方案验证：跟踪前沿技术，用数据验证方案是否值得投入。
4. 配合效果评估与迭代：参与评测设计与 bad case 分析，持续优化召回与生成。

【岗位要求】
1. 27届硕士学历，计算机、人工智能、软件工程等相关专业。
2. 熟悉 Python 或 Java，算法与数据结构基础扎实。
3. 在 LLM、NLP、知识图谱、RAG 等至少一个方向有项目或研究积累（课程、竞赛、科研、实习均可）。
4. 学习能力强，能独立定位问题，能读英文技术文档。
5. 愿意理解业务，能和算法、产品、业务同学协作。

## 匹配分析
- 匹配理由：同一校招项目下的知识库/RAG 岗，职责含 Agent 设计与政策问答落地；27届硕士可投。
- 缺口：岗名偏算法；与 Agent 开发岗同项目限投 1 次，不能两岗都投。
- 限投：官网职位页：27届校招项目允许投递1次
