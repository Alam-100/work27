## 岗位简介
【岗位职责】
1. 参与 AI Agent 产品的设计与研发，负责任务规划、工具调用、状态管理、上下文管理和工作流编排等模块。
2. 基于大语言模型及相关 API 开发 Agent 应用，完成技术方案设计、原型验证和工程落地。
3. 参与 RAG 系统建设，包括数据处理、检索、重排、生成及效果评测。
4. 建设 Agent 评测与可观测体系，通过评测集、运行日志、Trace 和用户反馈分析准确率、成功率、延迟及调用成本。
5. 优化 Agent 系统的稳定性和安全性，包括结构化输出、失败重试、超时降级、权限控制及 Prompt 注入防护。
6. 与产品和业务团队协作，将业务需求转化为可验证的技术方案，并撰写技术设计与复盘文档。

【任职要求】
1. 2027届计算机、软件工程、人工智能或相关专业硕士、博士研究生，能够连续实习3个月及以上。
2. 熟练使用 Python，具备数据结构、算法和软件工程基础。
3. 理解大语言模型基本原理，了解 Prompt Engineering、上下文窗口、结构化输出、Function Calling。
4. 了解 Agent 基本设计模式，如 ReAct、Plan-and-Execute、Reflection、工作流或状态机编排。
5. 了解至少一种 Agent 或大模型应用框架，如 LangGraph、LangChain、LlamaIndex、Semantic Kernel 或 CrewAI。
6. 能够完成 API 开发、数据库操作、Git 协作、测试和问题排查。
7. 能够从业务目标出发定义技术方案和效果指标。

**加分项**
- 有可演示的 Agent、RAG 或大模型应用项目，并能说明架构、评测和迭代。
- 有 Agent 评测、数据构造或 A/B 实验经验。
- 熟悉向量数据库、搜索引擎、重排模型或知识库构建。
- 了解 MCP、模型 API 接入、Agent 可观测性或安全防护。
