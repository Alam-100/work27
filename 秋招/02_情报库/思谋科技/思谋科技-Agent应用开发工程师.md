## 岗位简介
【岗位职责】
1. 工业场景 Agent 应用开发：设计并实现面向工业场景的智能 Agent（工业知识问答、工艺流程辅助、产线异常分析），做成能跑在产线上的软件产品。
2. 全栈快速验证：利用 AI 辅助开发工具独立完成从需求理解到 MVP 原型交付。前端背景侧重体验并补齐后端与 Agent 逻辑；后端/算法背景侧重稳定性并补齐可交互功能。
3. AI-Native 工程实践：把新的 AI 开发范式落到工业场景或内部工具链。

【任职要求】
1. 熟练掌握 Python 或 TypeScript 至少其一，理解异步、事件驱动，具备 API 集成与调试能力。
2. 对 Codex / Claude Code / Cursor / v0 等 AI 编程工具有实际使用经验，了解能力边界。
3. 熟悉常见 Agent 架构（ReAct、Plan-and-Execute、Multi-Agent）及记忆、工具调用、规划器；有实际 Agent 软件系统落地经验（个人项目、实习或工作均可）。
4. 能从用户视角定义问题，独立完成功能拆解并落地为可演示的 MVP。
5. 能够对 Agent 应用做模块化设计（规划/执行/记忆/工具分离）。
6. 愿意跟进新工具并分享实践；适应短期工厂驻场或产线调研。

**加分项**
- 用过 LangChain 等 Agent 编排框架，并理解设计取舍。
- 既写过 Python 后端（FastAPI）也写过 TypeScript 前端。
- 有工业软件开发经验（MES、设备数据采集、维修工单等）。
