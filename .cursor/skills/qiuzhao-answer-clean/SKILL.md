# 面经答案清洗（原稿 → 标准答）

## 目标

1. **同步框架**：按各公司真实题库分节生成/刷新「答案原稿」（元数据 + **每类题型 1 个题号实例**）与标准答全量进度表。  
2. **清洗**：把用户填写的未修剪答案洗成标准书面答；进度表支持分批。

## 与其它 Skill 的边界

| Skill | 关系 |
| --- | --- |
| `qiuzhao-mianshi-search` | 上游：只维护题库**问题列表**；题库变了用本 Skill 同步框架 |
| `qiuzhao-interview-answers` | 对岗自我介绍（`08_`）；不替代公司标准答 |
| `qiuzhao-oral-qa` | 练口；书面清洗走本 Skill |
| DORA 手册 | 可核对项目事实；原稿未写的经历不编造 |

## 题号与节缩写（动态）

格式：`### A-{节缩写}-{序号}`，序号与题库该节编号一致。

生成规则（与脚本一致）：

1. 读题库 `#分节` 标签行（跳过标题行）；同步时写入稳定块 ID `^qz-…`。  
2. **别名表优先**（见脚本 `SECTION_ALIASES`：行为面→行为、架构与Agent设计→架构、工程八股→工程……）。  
3. 未命中：去掉空白，按「与/和」取第一段，过长截到 8 字。  
4. 手撕默认进度 `跳过`。

**跳转**：分节是标签不是标题 → 用 `[[题库#^qz-RAG]]`（必须带 `#^`），禁止 `[[题库#RAG]]` 与 `[[题库^qz-RAG]]`。  
**原稿结构**：块链只挂在 `## 分节` 下一次；`###` 实例不写题干、不重复题库链。

**不要**维护一份写死所有公司分节的全局模版；分节以各公司题库为准。

## 踩坑：Obsidian 链接三易混

| 写法 | 对错 | 说明 |
| --- | --- | --- |
| `[[题库#RAG]]` | ❌ | `#RAG` 是**标签**不是标题 → 常跳到文首 |
| `[[题库^qz-RAG]]` | ❌ | 缺片段分隔符 `#` → 被当成另一条笔记名，打开全新界面 |
| `[[题库#^qz-RAG]]` | ✅ | 跨笔记块引用：`#` 分隔片段 + `^` 标块 ID |
| `[[标准答#A-RAG-1]]` | ✅ | 标准答是 `###` **标题**，用 `#标题`，无 `^` |

题库行内锚点仍写：`#RAG ^qz-RAG`（标签 + 行尾块 ID）；**出站 wikilink** 才用 `#^`。

## 进度表状态

`未处理` / `已处理` / `无原稿` / `跳过` — 写在标准答文首。

## 口令

```text
同步答案框架：全部
同步答案框架：<公司>
清洗答案：<公司>
继续清洗：<公司>
清洗答案：<公司> 批次：<节缩写或题号列表>
```

## 工作流

### 0. 同步答案框架（优先）

1. 优先执行：

```powershell
py -3.12 qiuzhao\scripts\sync_answer_frameworks.py
# 或
py -3.12 qiuzhao\scripts\sync_answer_frameworks.py --company 阿里巴巴
```

2. 脚本行为：扫描 `*-Agent面经题库.md`（排除牛客综摘）→ 给分节标签补 `^qz-…` → 写原稿（`##` 下一条 `#^` 块链 + **每节仅第 1 题空壳**；已有非空答案正文保留）→ 刷新标准答全量进度表。  
3. 脚本不可用时，按同规则手写/补节（分节跳转必须用 `[[…#^qz-…]]`）。  
4. 短报：公司数、每家节数/题数。

### 1. 清洗答案

1. 解析公司；定位题库 / 原稿 / 标准答。缺题库 → 停止。缺框架 → 先跑同步。  
2. 刷新进度：原稿有实质 `### A-…` → 可标 `未处理`；无 → `无原稿`；手撕默认 `跳过`。  
3. 本批：`未处理` 且有原稿；默认每会话 **8～12** 题；点名批次则只洗该批。  
4. 清洗（禁止口述化）：去语气词/闲聊/无关段，理顺顺序；不编造经历。  
5. 写入标准答 `### A-…` + 回链题库分节块 ID（`[[…题库#^qz-…]]`）；进度 → `已处理`。  
6. 题库行尾挂 `[[…面经答案#A-…]]`；禁止改题干、禁止往题库塞答案正文。  
7. 短报：本批 N / 剩余未处理 M；需要时提示 `继续清洗：<公司>`。

## 非目标

- 不在全局 Templates 里维护全公司题单  
- 不转口述卡、不搜网填答案、不接豆包、不改 SPA  

## 完成前检查

- [ ] 同步：题库分节有 `^qz-…`；原稿 `题库：` 行含 `#^`、链接在 `##` 下、实例无题干；进度表对齐  
- [ ] 清洗：`### A-…`、进度、题库仅行尾锚点；回链用 `#^` 非 `#分节` / 非裸 `^`  
- [ ] 未覆盖用户已填非空原稿块  
- [ ] 未口述化、未编造经历
