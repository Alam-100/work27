# 秋招面试准备主控（专享）

## 与 qiuzhao-assistant 的分工

| Skill | 职责 |
| --- | --- |
| **qiuzhao-assistant** | 情报入库、Agent 队列、投递跟进、面经图片题库、日更 |
| **本 Skill** | 对**某一公司某一岗位**做面试材料阶段准备与验收 |

投递状态、截止日、队列消费仍走控制台 / `qiuzhao-assistant`，本 Skill **不写** `05_投递进度`。

## 真相源与路径

- Vault 根：`QIUZHAO_VAULT`（默认 `E:\obsidian\My_docs`）→ `秋招/`
- 逻辑键：`公司` + `岗位`（无实体「公司文件夹」）
- JD：`秋招/02_情报库/{公司}/{公司}-{岗位}.md`（或用户指定 stem；`vault_io` 按 stem 递归查找，兼容旧扁平路径）

## 主控命令格式

```text
公司：<公司名>
岗位：<岗位名>
执行阶段：岗位分析 / 面经搜寻 / 自我介绍和回答 / 口述卡与模拟卷 / 全流程
情报卡：<可选 stem，默认 {公司}-{岗位}>
输出要求：<可选；默认 Markdown>
```

公司、岗位或情报卡无法唯一确定时，**先澄清再执行**。

## 标准工作流

全流程在**当前聊天**串行完成，不跨聊天、不跳步：

```text
岗位分析与匹配 ──> 面经搜寻 ──> 自我介绍和回答 ──> 口述卡与模拟卷
```

阶段四可按用户要求跳过；也可单独口令 `批量口述` / `出模拟卷`（见 `qiuzhao-oral-qa`）。

### 阶段一：岗位分析与匹配

调用 **`qiuzhao-job-analysis`**。

验收产物：

```text
秋招/08_面试准备/{公司}-{岗位}/岗位分析与经历匹配.md
```

### 阶段二：面经搜寻

阶段一通过后调用 **`qiuzhao-mianshi-search`**。

验收产物：

```text
秋招/08_面试准备/{公司}-{岗位}/常见问题与面经汇总.md
```

### 阶段三：自我介绍和回答

阶段一、二均通过后调用 **`qiuzhao-interview-answers`**。

验收产物（默认）：

```text
秋招/08_面试准备/{公司}-{岗位}/自我介绍和回答.md
```

并检查已回写/链接 `03_面经/{公司}-面经与复盘.md`。用户明确要求 DOCX 时再出 docx 并做视觉检查。

阶段三须**强制引用** DORA 面试手册（`docs/interview-manual/` ≡ `秋招/06_知识库/DORA面试手册/`），可选核对 DORA 代码；细则见 `qiuzhao-interview-answers`。手册不可达则阶段三失败，不得仅凭画像硬写技术深答。

### 阶段四：口述卡与模拟卷（可选）

阶段二通过后即可调用 **`qiuzhao-oral-qa`**（不必等阶段三；有常见问题表或公司题库即可）。

验收产物：

```text
秋招/09_口述题答/{主题}/{QID}-*.md   # 增量/去重后的口述卡
秋招/09_口述题答/_索引.md            # 联动索引已刷新
秋招/08_面试准备/{公司}-{岗位}/模拟面试卷.md
```

可选：`09_口述题答/_导出/doubao_bank_*.json`。不把答案写回公司面经题库。

## 事实规则（全局）

1. **求职画像**是履历数字、角色、结果的最高依据。
2. **DORA 面试手册**是项目技术深度与「已落地/部分/未做」边界的最高依据（阶段三强制）。
3. 情报卡「已具备/待补齐」仅作初值，不得覆盖画像或手册。
4. 冲突时：履历以画像为准并标「待确认」；能力边界以手册覆盖标签为准；禁止把「参与」写成「主导」，禁止虚构经历/数字，禁止把缺口写成现网能力。
5. 缺上游产物或手册不可达时停止并指出缺什么，建议先跑对应阶段；不得用其他公司材料代替。

## 文件覆盖

- 不得静默覆盖已有标准输出；已存在则询问「更新原文件 / 另存版本」。
- 用户指定文件名或格式时服从用户；否则用上述标准名。

## 当前聊天职责

1. 解析公司、岗位、阶段、情报卡 stem。
2. 检查情报卡与 `求职画像.md` 是否存在且可唯一识别。
3. 按阶段调用子 skill，验收落盘路径与完成标准。
4. 以 `08_面试准备/{公司}-{岗位}/` 文件作为阶段交接依据，不依赖未落盘的临时上下文。
5. 任一阶段遇登录墙、权限、输入缺失或事实冲突 → 当场反馈，不得硬生成下游文档。
