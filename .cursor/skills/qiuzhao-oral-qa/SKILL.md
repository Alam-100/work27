# 口述题答与模拟卷（秋招专享）

## 目标

跳过「教科书答案」与「未整理搜索草稿」中间层；帮用户把**点名的题**整理成可开口话术。  
口述卡**给用户练口**；Agent 只在点名时维护，禁止借机扫全库。

## 与其它 Skill 的边界

| Skill | 关系 |
| --- | --- |
| `qiuzhao-mianshi-search` | 上游：只收集/清洗**问题**与证据 |
| `qiuzhao-interview-answers` | 对岗自我介绍与个性化深答；**不替代**本 Skill 的跨公司主题卡 |
| `qiuzhao-answer-clean` | 公司**标准书面答**（`06_知识库/面经答案/`）；本 Skill 只管练口，不替代书面清洗 |
| `qiuzhao-interview-prep` | 主控可选阶段四调用本 Skill |
| DORA `06-interview-qa-bank` | 项目深挖**优先复用**，禁止另写冲突话术 |

## 路径约定

| 角色 | 路径 |
| --- | --- |
| 问题源 | `06_知识库/公司面经摘录/{公司}-Agent面经题库.md`（只列问题） |
| 标准书面答 | `06_知识库/面经答案/{公司}-Agent面经答案.md`（由 `qiuzhao-answer-clean` 维护；可选作润色输入） |
| 常见问题表 | `08_面试准备/{公司}-{岗位}/常见问题与面经汇总.md` |
| 口述卡 SSOT | `09_口述题答/{主题}/{QID}-{短标题}.md` |
| 索引 / 必练 | `09_口述题答/_索引.md` |
| 答法模版 | `09_口述题答/_答法模版.md` |
| 模拟卷 | `08_面试准备/{公司}-{岗位}/模拟面试卷.md` |
| 导出 | `09_口述题答/_导出/doubao_bank_{公司或主题}.json` |
| 手册 | `06_知识库/DORA面试手册/` ≡ DORA `docs/interview-manual/` |
| 模板 | `Templates/秋招-口述题答卡.md`、`Templates/秋招-模拟面试卷.md` |

主题目录：`Agent` / `RAG` / `行为面` / `项目深挖` / `模型与训练` / `工程与系统` / `业务与产品`。  
手撕不写长解 → `手撕与算法/高频手撕清单.md`。

## 非目标

- 不为每道公司面经题建卡；不建未整理答案草稿箱（书面原稿/标准答走 `qiuzhao-answer-clean` → `面经答案/`）
- 不借「润色」做全库批处理
- 不写回公司面经题库（题库行尾锚点由 answer-clean 维护）

## 口令

**推荐（减轻负担，默认走这条）：**

```text
润色口述：<题干或 QID>
要点：<关键词/半成品，可空>
```

**其它（须用户明确点名公司/主题/卷）：**

```text
批量口述：<公司名>
主题口述：<Agent|RAG|...>
出模拟卷：<公司>-<岗位>
导出豆包题库：<公司或主题>
```

或由主控：`执行阶段：口述卡与模拟卷`。

## 工作流

### 0. 按需润色（默认主路径）

1. 解析 `润色口述` 的题干或 QID；若有「要点」则当作用户半成品，**不要求**其先整理入库。  
2. 一次只处理 **1 题**；用户点名一小撮时 **≤3 题**，禁止扩扫全库。  
3. 已有卡则更新；无卡再新建（映射 DORA Q / 主题目录）。  
4. 按 [[_答法模版]] 四步改写：结论 → 边界 → 证据 → 勿说。  
5. **优先改好 30 秒骨架与开口检查**；90 秒仍 ≤3 证据点。  
6. 项目事实走 DORA 手册门禁；用户未提供的个人经历不编造。  
7. 若改了联动，轻量刷新 `_索引` 对应行；不必重写全索引。

### 1. 收集候选题（仅批量/主题/出卷时）

1. 读公司题库 +（若有）`08_` 常见问题表。  
2. 语义去重；同义问法合并到一张卡的「同义问法」。  
3. 映射已有 QID 或 DORA `06-interview-qa-bank` 题号；能复用则更新联动，不新建冲突卡。  
4. 优先覆盖 `_索引` **常驻必练**；其余不强行补卡。

### 2. 写/更新口述卡

每卡必须含：

1. 规范题干 + 2–4 同义问法  
2. `related` / `prereq` / `followups`（QID）  
3. **30 秒骨架**（脱稿可念）  
4. **90 秒展开**（≤3 证据点）  
5. 开口检查（3 关键词 + 卡壳先说）  
6. 勿说（未做/易夸大）  
7. 依据（手册路径 + 覆盖标签；行为题绑画像）

硬规则：

- 禁止教材堆砌与超长条目列表。  
- 项目断言必须可追溯手册覆盖标签；`未做-演进` 只能划界。  
- **不写回**公司面经题库。

### 3. 刷新索引联动

更新 `_索引.md`：必练表保持稳定；主题表 + 推荐复习路径按需补行。

### 4. 公司模拟面试卷

写入 `08_.../模拟面试卷.md`：

- 一面 / 二面 / HR，共 8–12 题  
- 优先该公司高频 + 联动邻题 + 必练 QID  
- 每题：题干、口述卡 wikilink（无卡可空，只留题干）、时长、考察点  
- 文末：**打印版**（仅题干）+ **自测版**（题干后空行再给骨架）

### 5. 导出（可选）

生成 `doubao_bank_*.json`（可用 `qiuzhao/scripts/export_oral_qa_doubao.py` 从卡片重导）：

```json
[{"id":"AGT-10","question":"...","answer_30s":"...","answer_90s":"...","tags":["Agent"],"related":["AGT-11"]}]
```

本期不接豆包 API。

## 完成前检查

- 润色路径：只动点名题；30s/开口检查优先；已对手册/勿说。  
- 批量路径：新卡均有 30s/90s/联动/勿说；`_索引` 已更新；模拟卷引用有效 QID（允许无卡题干）。  
- 公司题库未被写入答案。  
- 若导出：JSON 字段齐全可手工导入。
